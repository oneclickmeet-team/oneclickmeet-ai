# AI 파트 답변 (AI → 서버)

> 서버 파트 확인 요청(ask-ai-team.md)에 대한 답변입니다. · 2026-11-09
> 연동 상세는 [BACKEND_INTEGRATION.md](BACKEND_INTEGRATION.md)를 봐 주세요.

## 1. 시연 환경에서 AI 서버를 띄울 수 있나요?

**네, 띄울 수 있습니다.** 다만 시연용 서버는 아직 띄우지 않았습니다.

- **서버 주소(`AI_SERVER_BASE_URL`)와 서비스 키(`AI_SERVICE_KEY`)는 수요일(11/11) 전까지 전달하겠습니다.**
- 코스 추천이 AI 서버 없이는 502가 나는 것 확인했습니다. 시연 전에 AI 서버가 떠 있는지 `/health`로 확인하겠습니다.

## 2. 비전 폴백은 시연에서 켜나요?

**AI 파트 의견으로는 시연에서 켜 두는 게 좋겠습니다.** 캡쳐를 OCR로 못 읽었을 때 한 번 더 읽어 주기 때문에, 시연 중 "찾지 못했어요"가 나올 가능성이 줄어듭니다.

| 항목 | 값 |
|---|---|
| 제공자 | OpenAI |
| 모델 | `gpt-4o-mini` |
| 비용 한도 | **100달러** (OpenAI 계정 한도. 장소 태그 판단과 같은 키를 씀) |
| 설정 | `AI_VISION_FALLBACK=openai`, `AI_VISION_FALLBACK_MODEL=gpt-4o-mini` |

- 폴백은 OCR + 규칙으로 장소를 못 찾았을 때만 호출되므로, 모든 이미지 요청에 비용이 드는 것은 아닙니다.
- 폴백을 켜면 캡쳐 원본이 OpenAI로 전송됩니다.
- **이미지 인식 대기 시간 70초는 충분합니다.** 38건 평가에서 가장 오래 걸린 경우가 약 60초였습니다. 링크·텍스트 30초, 코스 추천 15초도 그대로 두시면 됩니다. 더 오래 걸리는 경우가 생기면 알려 드리겠습니다.

## 3. 코스 추천 카테고리 코드 7개가 확정값인가요?

**네, 확정값입니다.** 10월 30일 회의에서 7개로 확정하기로 했습니다.

| 코드 | 이름 | 범위 |
|---|---|---|
| `MEAL` | 맛집 | 음식점 (술집 제외) |
| `CAFE` | 카페 | 카페·디저트 |
| `BAR` | 술집 | 술집·바·이자카야 |
| `ACTIVITY` | 놀거리 | 방탈출·보드게임·공방·포토부스 등 체험 |
| `CULTURE` | 전시·문화 | 전시·공연·미술관·도서관 |
| `WALK` | 산책 | 공원·산책로·전망·관광명소 |
| `SHOPPING` | 쇼핑 | 소품샵·편집숍·시장 |

지금 서버가 쓰는 코드와 같으니 그대로 쓰시면 됩니다. 코드 목록은 `GET /internal/v1/categories`로도 받을 수 있습니다.
